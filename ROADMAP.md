## Roadmap
This roadmap is meant to help our community plan for our official launch at the UN Open Source Week conference in the summer of 2027.  We plan to do a soft launch this fall and then iterate and improve based on feedback from users.

Feel free to contribute changes or add items that we may have missed.

### Soft Launch of MVP - Fall 2026 (Target Nov 1 2026)

**MVP Features**
- Must have
    - Accurate SDG classifier - over 75%
    - UI
        - one analysis button with informed process messages
        - clear SDG educational language and instructions
        - support for github, gitlab, & bitbucket
    - Outputs
        - New output "context" folder with initial draft of 4 files
            - metadata.json (using code.json schema)
            - publicode.yaml (using publicode.yaml schema)
            - README.md (with plain english description of SDG and attestation statement "highly relevant ...")
            - debug.json (for debugging classification predictions)
    - Deployment
        - publicly available URL
        - low or no cost hosting (LAI AWS, CHAOSS linux AWS, ...)
    - Community Engagement
        - flushed out contributors guide with clear AI policy
        - outreach to a set of maintainers to test our tool
        - regular development and working group meetings
        - clear setup/install instructions
- Nice to have
    - Accurate SDG classifier
        - over 75%
        - internal lightweight model or dependable/fast/free API call
        - process for evaulating changes to models
    - UI
        - probability display with scrollbar, color scheme, and customizable thresholds.
        - improved design asthetics
    - Outputs
        - automate filling in additional metadata fields based on API calls
    - Deployment
        - CICD pipeline with testing
        - maintenance plan
    - Community Engagement
        - clear user instructions
        - outreach to indexer orgs & sites (Software Heritage, DPG Alliance, CMS, ...)
